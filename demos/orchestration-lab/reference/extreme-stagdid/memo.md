# Memo — does the TWFE critique change the answer here?

Two-way fixed effects and every modern heterogeneity-robust estimator I ran — Callaway-Sant'Anna under both control-group choices, and Sun-Abraham — land in the same neighborhood: a 3.7 to 4.7 percent decline in teen employment following a state minimum-wage increase (naive TWFE −0.0365; Callaway-Sant'Anna −0.0398/−0.0400; Sun-Abraham −0.0400; Roth-Sant'Anna −0.0471, all SEs 0.011–0.013). The one estimator that produced a wildly different number — a supposed 37 percent decline — did so because of a coding error, not a real finding: `staggered::staggered()` requires never-treated units coded `Inf`, and this dataset's own convention codes them `0`. Passing `0` through unchanged makes the package treat "never treated" as "treated since the start of time," and the result should have been caught on inspection, not reported.

So does the negative-weighting critique matter here? In theory, yes — Goodman-Bacon (2021) is correct that TWFE under staggered timing implicitly runs comparisons where an already-treated county serves as the control for a later-treated one, and those comparisons can carry negative weight if the effect changes over time. In this dataset, that comparison type carries only 5.4 percent of the naive regression's identifying weight; 86.3 percent comes from clean treated-vs-never-treated comparisons. That is why the naive TWFE number sits inside the range the modern estimators produce rather than diverging from it. The critique is real as a general warning and empirically small as applied to this specific panel.

The event-study check adds one more piece: pre-treatment coefficients at t−2 and t−1 are both statistically indistinguishable from zero, so parallel trends looks supported, and the effect is not significant on impact but grows and becomes significant a year later. A single pooled ATT hides that the effect builds rather than arrives all at once.

The number I would report: an ATT of approximately −0.04 (a roughly 4 percent decline in teen employment), stated as robust across five independently specified estimators, with the caveat that the effect appears to intensify in the year after adoption. I would not say "TWFE is fine here, ignore the modern literature" — the check that it is fine is itself only valid because the Bacon decomposition came out favorable, and a different staggered-adoption design could easily fail that same check. I would also not say "always use the modern estimator regardless" — in this application it changes almost nothing about the substantive conclusion, and reflexively citing the critique without checking it is exactly the failure mode this exercise is built to catch.
