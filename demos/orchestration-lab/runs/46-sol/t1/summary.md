# Design summary

The reshaped analysis design contains **400 respondents**, **8 primary randomized tasks per respondent**, **2 profiles per task**, and **6,400 primary-task profile rows**.

The repeated reliability outcome is attached to task 1 in selected_repeated and agree. It is a reliability check, not a ninth randomized profile task.
